# PAZ Viewer

[English](README.md) | **Русский**

Программа для Windows: просмотр и правка **архивов PAZ** движка визуальных новелл **Musica**
от minori (*12の月のイヴ*, *eden\**, *ef*, *Natsuzora no Perseus*, *Trinoline*, *Supipara* и другие).

Откройте архив, ходите по нему как по папке, смотрите картинки, скрипты и звук, извлекайте файлы,
заменяйте или добавляйте их и сохраняйте архив обратно — целиком или маленьким патчем, который
игра подгружает поверх оригинала.

## Возможности

- **Встроены ключи 29 игр на движке Musica** (из базы GARbro). Игра определяется сама при
  открытии архива.
- **Папки, как в Проводнике**: дерево папок, содержимое текущей папки и строка пути; или все файлы
  одним списком (Ctrl+L).
- **Три вида**: Таблица (размер, сжатый размер, смещение, сжатие, статус), Список и Эскизы на
  шахматном фоне (Ctrl+1/2/3).
- **Предпросмотр** (F3): картинки (PNG, BMP, JPEG), текст скриптов (Shift-JIS), звук (OGG и WAV,
  в том числе файлы без расширения) с кнопками «Воспроизвести» / «Стоп».
- **Извлечение** выбранных файлов, папок или всего архива — в папку с именем архива, с
  подпапками.
- **Замена и добавление файлов** перетаскиванием, через меню или контекстное меню.
- **Сохранение** архива целиком или **только изменений как патча** (`scr1.paz` … `scr9.paz`):
  игра подгружает его поверх `scr.paz`, оригинал не трогается — лучший вариант для перевода.
- **Многотомные архивы** (`bg.paz` + `bg.pazA` … `bg.pazN`) открываются как один архив и
  сохраняются снова томами, как у оригинального упаковщика (300 МиБ, файл между томами не
  делится).
- **Побайтная идентичность**: архив без изменений сохраняется точно как оригинал.
- **Безопасное сохранение**: при первой перезаписи оригинал остаётся как `.paz.bak` (каждый том
  тоже).
- **Интерфейс на английском или русском** (меню «Язык»; по умолчанию английский), встроенная
  справка (F1).
- Запоминает размеры панелей, вид, панель предпросмотра и язык.

## Как пользоваться

1. Запустите `pazview.exe` и откройте `.paz` (Ctrl+O), перетащите его в окно или передайте в
   командной строке: `pazview.exe путь\к\scr.paz`.
2. Смотрите содержимое и предпросмотр; извлекайте Ctrl+E (выбранное) или Ctrl+Shift+E (всё).
3. Чтобы изменить файлы, перетащите новые файлы в список: файлы архива с тем же именем или путём
   заменяются, остальные можно добавить как новые.
4. Сохраните Ctrl+S или Ctrl+P — только изменения, патчем.

### Клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+O | Открыть архив |
| Ctrl+S / Ctrl+Shift+S | Сохранить / Сохранить как |
| Ctrl+P | Сохранить изменения как патч |
| Ctrl+E / Ctrl+Shift+E | Извлечь выбранные / Извлечь все |
| Ctrl+R | Заменить выделенный файл |
| Del | Отменить замену / удалить новый файл |
| Ctrl+A | Выделить всё |
| Ctrl+L | Все файлы одним списком |
| Ctrl+1 / 2 / 3 | Таблица / Список / Эскизы |
| Enter | Открыть папку / проиграть звук |
| Backspace, Alt+↑ | На уровень вверх |
| F3 | Панель предпросмотра |
| F1 | Справка |

## Ограничения

- Имена файлов внутри архива хранятся в Shift-JIS: кириллица в именах не поддерживается
  (содержимое файлов может быть любым).
- Предпросмотра `.sqz`, `.avi` и других форматов движка пока нет (их можно извлекать и
  заменять).
- Оверлей (`scr1.paz`), открытый без основного архива рядом и без файлов со слоем RC4, может
  показать неверное название игры (на содержимое это не влияет).
